# FluentGpu scroll-frame GPU rework — retained tiled slices, render-pass discipline, off-frame uploads, Present1

## 0. Why today's scroll frame costs ~5 ms (confirmed in code)
- The render turn (AppHost.cs:1157-1220) re-records the whole scene every tick; scroll content survives only as a translated byte copy (CopySpanFromPriorTranslated), so every frame still replays every primitive in the window through SubmitStreaming to a ClearRenderTargetView'd back buffer (:2096). RepaintPolicy.Decide sends scroll (>60% coverage) to FullDirect by design (RepaintPolicy.cs:14-17).
- The viewport's top feather is a PushEdgeFadeLayer (SceneRecorder.cs:2388) whose strip path copies back-buffer strips out twice per fade (BeginStripTargetCopySource → Barrier(RENDER_TARGET → COPY_SOURCE) at D3D12Device.cs:4508, again at :4611), each a tiler flush + resolve.
- Glyph band upload, FlushUploads, and DrainOne (baked blur) sit on the DIRECT list between the timestamp start and the scene (:1874-1884).
- IDXGISwapChain::Present with no DXGI_PRESENT_PARAMETERS (:4874); no ID3D12GraphicsCommandList4 binding exists anywhere in FluentGpu.Windows, so every RT starts with a full clear and stores fully.

## A. Retained tiled content layer ("picture cache")
### A.1 Decision: engine-side composite into the swapchain (option i), not native DComp surfaces (option ii)
Reasons: (1) effects the engine owes (backdrop acrylic sampling scrolled content, analytic edge feather, self-blur, rounded AA clips, nested scrollers in effect groups) cannot be expressed in IDCompositionVisual trees without WinRT composition (excluded); half-native (chrome in swapchain, content in DComp visuals) reintroduces non-atomic Present vs Commit — a sticky header posed in the swapchain and rows translated by a DComp transform could land one DWM frame apart; the poser's presentSec = tick + (1+lat)·refresh law is calibrated to the latency-waitable swapchain. (2) Verifiability: (i) is checkable by the GPU pixel-identity probe (--repaint-identity) and the headless reference. (3) Cost gap is small: compositing ~12 window-covering tiles is one 4.1 MP textured fill (~0.3 ms on the X1-85). One backend, no switch.
### A.2 Structure
Tiles 1024×512 device px BGRA8 (2 MiB), one texture per tile (whole-RT render pass CLEAR/DISCARD — tiler-friendly). Slice kinds: Static (everything not under a scroll root/effect, split into "under"/"over" bands by paint order), Scroll (one per scroll root, recorded in CONTENT space, composited at the posed device-snapped offset), Effect (nodes with compositor-time params: sticky, collapse/hero, parallax, fade, group opacity, self-blur, edge fade, acrylic — bucketed region surfaces via the LayerTargetBucket.Dim ladder). >16 slices ⇒ effect slices under the same scroll root fold into the scroll slice (WebRender squashes past 8, picture.rs:68-70). Static under/over split comes from the recorder: the main walk treats each scroll root as a skip-root and emits a CompositeSlice marker in its place.
```csharp
namespace FluentGpu.Render.Tiles;
```

### A.3 Invalidation
Scroll slices are recorded in content space, so a pure scroll changes zero bytes: the exact-span copy (SceneRecorder.cs:1423-1442) covers clean rows; the translated-copy branch B (:1443-1507), spanMoveSig, NoteTranslatedCopy, TranslateCopiedSpan and the InMotion glyph-softness patching are DELETED. MixScrollViewport stops mixing ShownOffset (:2809). Per-tile reasons: Content (record-dirty node old∪new bounds hits the tile), PrimCount (a row realized/parked into it), ValidRectChanged (coverage grew into a partially covered tile), ScaleChanged/SliceGeometry/BackgroundOrTheme (whole slice), NoTexture/Evicted/Degraded (budget). Census counts per reason per frame; ScrollProbe.Cost(TileRaster) rows carry tiles/bytes.
### A.4 Raster scheduling — never blank
Each render turn, before the composite, same command list: per slice TileGrid.Needed → raster needed tiles with Invalid != None; visible tiles are rastered in the same submission that composites them (valid by construction); the ahead band uses the Virtualizer's |v|·LookaheadS; one tile row retained behind in both directions (WebRender picture.rs:2330-2335). Tiles outside coverage are not requestable (agrees with the poser's clamp, ScrollPoser.cs:117-124). Per-tile replay reuses the streaming decoder with a shifted viewport (the TryBeginRegionLocalBlur mechanism, D3D12Device.cs:4643-4665) + RepaintCull halos; the per-slice span index skips clean-span byte ranges missing the tile.
### A.5 Composite pass
One pass on the back buffer, BeginRenderPass(DISCARD → STORE), painter-ordered:
```csharp
public enum CompositeKind : byte { Tiles, Region, EraseVideoHole }
public readonly record struct CompositeItem(int SliceId, CompositeKind Kind, Affine2D Transform, float Alpha, RectF Clip, CornerRadius4 ClipRadii,
    EdgeFeather Feather, float BlurSigma, AcrylicRecipe Acrylic, byte BlendCopy);
```
Scroll content transform = Translate(round(WindowOrigin − p′)·scale) from CompositorPaint(content) (poser unchanged). Sticky/hero/parallax/fade/thumb = Effect slices with posed Transform/Alpha/Clip (ApplyEffectChannel, AppHost.Scroll.cs:414-449), no re-raster. Group opacity <1 = Effect slice Alpha. Self-blur: slice surface blurred into a second surface when (σ, content epoch) changes; the pin cache (BlurPinKey, FindPin) is deleted. Edge fades: Feather multiplies the composite PS by the analytic feather (HLSL + C# port for headless) — strip path deleted. Acrylic: source = mini-composite of slices beneath its rect into the Kawase scratch (tiles are SRVs), blur + recipe, composite; zero back-buffer reads; refresh damage-keyed or offset-keyed while scrolling (~0.1-0.2 ms for a 1700×100 bar). Video: EraseVideoHole DestOut quad (keeps NoteVideoRect). Clips analytic in the composite PS (sdRoundRect); nested slices recursive, depth bounded.
### A.6 Memory (UMA)
TileBudgetBytes = clamp(3.5 × windowBytes, 32 MiB, 96 MiB) (~57 MiB at 2560×1600) — a default to be replaced by measurement. The deleted persistent canvas (16 MiB), warm canvas reserve (2×16 MiB) and strip scratch pay for it. Eviction: LRU weighted by distance from viewport, off-coverage first; a slice over budget degrades (InvalidationReason.Degraded) to direct raster for that frame — today's cost, never blank. LayerTargetTrim ages idle surfaces; LayerTargetCensus reports tiles.
### A.7 Pixel snapping / fractional scales
Slice origin floored to the device grid; residual fraction baked into the raster (SliceFrame.Residual*); poser translate already whole-device-pixel → composite is 1:1 point-sampled; text has the same subpixel phase at rest and in motion. Pinch zoom composites bilinear during gesture and re-rasters on settle (ScaleChanged; picture.rs:3764-3769).
### A.8 Poser / coverage
Contracts unchanged. Render turn becomes three-way: nothing changed → skip; only poses changed → composite-only turn (no record, no raster unless a needed tile is invalid); scene fresh → record slices, raster invalid tiles, composite.
```
render turn: presentSec → ScrollPoser.Tick → CompositorPaint/effect channels
  fresh? yes → SliceRecorder.Record (slice-space arenas, damage → tile invalidation)
  SliceScheduler: needed tiles (viewport ⊕ overscan ∩ coverage) → raster list (visible first)
  IGpuDevice.SubmitComposite: [copy-queue fence gate] tiles: BeginRenderPass(CLEAR→STORE) replay culled, End;
     backbuffer: BeginRenderPass(DISCARD→STORE) draw CompositeItems, End; Present1(dirty rects, scroll rect/offset)
```
## B. Render-pass discipline
Bind ID3D12GraphicsCommandList4::BeginRenderPass/EndRenderPass via generated comabi vtable (no hand-typed slots); query D3D12_OPTIONS5.RenderPassesTier, log once in [d3d12.present]; always callable (Tier 0 emulates). Tile raster CLEAR→STORE (bottom opaque static tile may DISCARD); back buffer DISCARD→STORE; blur scratch DISCARD→STORE. No ClearRenderTargetView on the back buffer; no COPY_SOURCE transition of any RT inside the frame (gate). Delete the strip snapshot path (TryBeginStripFade/EndStripFade, CopyStripSnapshot, EdgeFadeStripRestore, Begin/EndStripTargetCopySource, EdgeFadeStrips, EdgeFadeStripPack, EdgeFadeLayerClear) and the item-band PushEdgeFadeLayer emission. Opacity/blur groups become Effect slices rastered before the composite (leaf-first); SubmitWithLayers/WalkLayered/BeginLayeredFrame/LayerGroup/TryBeginRegionLocalBlur/bounded groups/LayerSubtreeProbe/BoundedGroupRegion go; OpacityLayerCompositor becomes SurfacePool + SliceCompositor.
```csharp
void RasterTile(int surface, in SliceRow s, in TileKey k, ReadOnlySpan<byte> stream) {
    D3D12_RENDER_PASS_RENDER_TARGET_DESC rt = default; rt.cpuDescriptor = _pool.Rtv(surface);
    rt.BeginningAccess.Type = D3D12_RENDER_PASS_BEGINNING_ACCESS_TYPE_CLEAR; rt.EndingAccess.Type = D3D12_RENDER_PASS_ENDING_ACCESS_TYPE_PRESERVE;
    _cl4->BeginRenderPass(1, &rt, null, D3D12_RENDER_PASS_FLAG_NONE);
    SetShiftedViewport(-(k.Tx * TileGrid.W) - s.Frame.OriginX, -(k.Ty * TileGrid.H) - s.Frame.OriginY, TileGrid.W, TileGrid.H);
    WalkStream(stream, cull: TileRect(k), spanIndex: s); FlushSegment(_streamLw, _streamLh); _cl4->EndRenderPass();
}
```
## C. Uploads and bakes off the timed frame
UploadQueue: D3D12 COPY queue + allocator ring + uploadFence; ImageTextureStore.FlushUploads records on the copy list and signals; textures left in COMMON (decay) → DIRECT first draw promotes to SRV without barrier. Readiness = fence compare (completedUploadFence ≥ image.UploadFence), never a wait; until then DrawImageCmd draws PlaceholderFill at final size and cross-fades on arrival (existing CrossFade) — no layout pop. Baked blur → COMPUTE queue with a CS port of dual-Kawase (math in AcrylicKawaseMath), same fence gating; unbaked shows unblurred/placeholder, never a hole. Glyph atlas dirty bands stay on DIRECT (new glyph visible this frame; KB-sized) bracketed by their own timestamps. One permanent budget UploadBudget.BytesPerTurn (start 8 MiB/turn) replaces DecodeScheduler.s_maxApplyBytesPerFrame/WeakTierApplyBytesPerFrame and every scroll-keyed variant; a live tunable, not an env var.
## D. Present
Present1 with DirtyRects = union of changed composite item dests (old∪new), rastered-tile dests, feather bands, thumb; on a pure scroll frame add pScrollRect = viewport, pScrollOffset = (0, Δdevice) (exact texel shift; feather bands in the dirty set). With FLIP_DISCARD the app still writes the whole back buffer; dirty rects shrink DWM's redraw (large on idle/hover frames). Keep FLIP_DISCARD + SetMaximumFrameLatency(1) + waitable.

## F. Missing scroll-linked APIs
**Status 2026-09-24: LANDED over the current posing path** (UI poser + render poser's compositor overlay; the retained tiles will consume the same rows). As built, differing from the sketch below: (1) transform-class rows of one node are FOLDED per tick into one `EffectTransform` (translations add, scales multiply) and written once through `IScrollPoseSink.PoseTransform` — so a parallax and a stretch on one node compose instead of the last row winning; (2) `StretchFromTop` is ONE `ScaleXY`/`Stretch` row whose pull-cancelling translation and top-centre pivot are derived in `EffectTransform.ToLocal` against whatever transform origin the node authored (no separate TransY row); (3) `Collapse(over, minH)` is the `PresentedH` row and `CollapseChildShift(over, minH)` its `ChildShiftY` partner (= presentedH − fullH, ≤ 0, the engine's trailing convention); the DSL `.Collapse(over, minH, CollapseAnchor)` adds the partner only for `Trailing` (Wavee's heroes are `Leading` — their presentation carries its own parallax) and, for `Leading`, the `CollapseClip` row (`ClipBottom`, a bottom-only cut at the presented edge, so the root needs no `ClipToBounds` and a stretching child fills a top overscroll); (4) the engaged edge compares against the signal itself (edge-only, never a steady-frame write); (5) `MeasureAll` is `VirtualListEl.MeasureAll`/`ListOptions.MeasureAll` + `ScrollState.MeasureAll`. Gates: `gate.scroll-effects.*` (VerticalSlice `ScrollEffectsSuite`) + `ScrollLinkedEffectTests` (Engine.Tests).
All are ScrollEffect rows evaluated by ScrollEffectEval on both threads, each targeting an Effect slice (no re-raster):

## G. Decisions and risks
Decisions: (1) option (i) engine composite; (2) delete the persistent-canvas/partial-repaint subsystem outright; (3) TileBudgetBytes default and 1024×512 tile size — measured, then pinned; (4) popups stay direct; (5) glyph band stays same-frame on DIRECT.
Risks: fractional-scale text identity (residual-fraction frame + 5-scale identity gate); Adreno RenderPassesTier may be 0 (correct either way, logged); per-tile decode CPU (span index; census); nested-slice recursion depth (bounded, gated); acrylic-over-scroll refresh cost during flings (~0.1-0.2 ms, measured); UMA memory with multi-monitor DPI (degrade, never blank); Present1 scroll-rect exactness (tile-scroll-identity gate).
